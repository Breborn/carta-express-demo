# LA PICADA DEL PUERTO — Carta Express Digital (Maqueta Breborn)

Maqueta minimalista tipo app de 1 pantalla para **cartas digitales y catálogos rápidos** con pedido directo a WhatsApp, pensada para picadas, botillerías, foodtrucks y emprendimientos de la V Región, Chile.

Página creada por [Breborn](https://breborn.cl).
